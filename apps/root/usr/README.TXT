AxolynOS - carpeta /usr
========================

Esta carpeta reserva espacio para los datos de usuario y los
programas que se instalen en el sistema.

El arbol basico del sistema es:

  /apps     aplicaciones instaladas
  /config   configuracion de aplicaciones (.axc)
  /etc      configuracion del sistema (motd, users.db, hostname)
  /home     carpeta personal de cada usuario
  /lib      bibliotecas (.axl)
  /system   archivos de sistema protegidos (.axsys)
  /tmp      archivos temporales
  /usr      datos de usuario y programas
